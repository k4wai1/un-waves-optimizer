# Investigación de Estados Elementales — subcarpeta de investigación

Esta subcarpeta contiene **una duda por archivo `.md`** para investigar los estados
negativos y la tonalidad de Wuthering Waves. El flujo de trabajo es:

1. Yo preparo aquí un `.md` por duda (estado + pregunta concreta).
2. Tú (usuario) lo **pegas uno por uno en Gemini**.
3. Me devuelves el resultado de Gemini.
4. Yo documento el estado con sus **nombres en inglés**, datos confirmados e
   **implementación** propuesta, y actualizo `docs/estados-elementales.md`.

## Convenciones de marcado

| Símbolo | Significado |
|---|---|
| ✅ | Confirmado con fuente (implementable) |
| ⚠️ | Parcial / ambiguo (revisar) |
| ❓ | Pregunta sin resolver (lo que hay que pasar a Gemini) |
